I just updated and added a few PHP scripts to <DeadLink
href="http://zhuoqe.org/svn/codeyard/trunk/">Code Yard</DeadLink> that might be
useful for some :)

- Updated and fixed some bugs in <DeadLink text="`parseCSV`" /> and <DeadLink
  text="`parseINI`" />.

- <DeadLink text="`speedometer{}`" /> — Class for simplifying calculation of
  script execution time.

- <DeadLink text="`walkDir{}`" /> — Class for recursively getting a list of
  directory contents. It returns both a multi-dimentional array, and a plain
  array with full paths, both types of output are optional increase performance.
  The number of directory levels to walk down into is also configurable.

- <DeadLink text="`rfile()`" /> & <DeadLink text="`wfile()`" /> — Functions for
  reading and writeing to local files. I wrote these about 3-4 years ago, and
  i've used them ever since, they've undergone some slight modifications since
  then, but their still basically the same. Their quite flexible, fast, and save
  a lot of time.

- <DeadLink text="`randpass()`" /> — Function with a quite self-explanatory
  name. Generates a random password of any desired length using the character
  ranges you specify. It can be made more flexible, but its perfect for most
  situations when you need to generate a random password.
